# 第 10 章 应用层：域名、网页与常用服务：实验文件

本章实验的完整步骤见教材[第 10 章“本章实验”](https://mingzifu9.github.io/computer-network/chapters/10-application/)。

| 实验 | 用到的文件 |
|---|---|
| 实验 10-1 ★ 查域名、看网页请求 | `lab10_1_url_parts.py` |
| 实验 10-2 ★ 搭工作室内部网站、DNS 和邮件服务器 | Packet Tracer |
| 实验 10-3 ☆ 用 Python 搭一个网页 | `lab10_3_client.py`、`mysite`；Wireshark |

## 程序说明

| 文件 | 作用 |
|---|---|
| `lab10_1_url_parts.py` | 实验 10-1 第三档：把一个网址拆成几部分 |
| `lab10_3_client.py` | 实验 10-3 第三档：用程序发一个 HTTP 请求，看看响应长什么样 |

运行方法：用 Thonny 打开后点“运行”，或在命令提示符中进入本文件夹后执行 `python 文件名.py`。程序只用 Python 标准库，不需要安装第三方库。

`mysite/` 是实验 10-3 用的小网站，启动方法见教材实验 10-3。
