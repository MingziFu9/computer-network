# 附录 E 实验报告模板与综合项目指南

## E.1 实验报告模板 { #e1 }

每个实验完成后提交一份实验报告。报告不求长，但要能让老师看出“你做了什么、看到了什么、想明白了什么”。

```text
实验名称：实验 X-X ________________          姓名：______  学号：______  日期：______

一、实验目的（照抄教材即可）

二、实验环境
    操作系统：             使用的软件及版本：

三、实验过程与结果
    按“第一档 · 跑通”“第二档 · 改一改”的步骤，每一步写清：
    1. 做了什么（命令、配置或操作）
    2. 看到了什么（截图，截图下方写一句说明）
    3. 和预期是否一致

四、实验记录表（照教材表格填写）

五、遇到的问题与解决方法
    问题：            原因：            解决方法：

六、思考与练习（回答教材中的问题）

七、收获与体会（2～3 句话）
```

**截图要求**：截取关键区域即可，不要整个屏幕；每张截图下方写图号和说明，如“图 3 PC0 ping 192.168.8.131 不通”。Packet Tracer 的截图要能看清设备名称和关键配置。

**评分要点**（每个实验满分 10 分）：

| 项目 | 分值 | 要求 |
|---|---|---|
| 第一档完成情况 | 4 | 步骤完整，截图清楚，结果正确 |
| 第二档完成情况 | 3 | 按要求改动，记录了变化并做出解释 |
| 记录表与思考题 | 2 | 数据真实、填写完整，思考题回答正确 |
| 问题记录与体会 | 1 | 如实记录遇到的问题和解决过程 |
| 第三档（选做） | 加 1～2 | 完成挑战任务的酌情加分，总分不超过 10 分 |

!!! warning "数据要真实"
    实验记录表中的数据要来自你自己的电脑和操作。不同电脑、不同网络得到的地址、时延各不相同，这很正常；照抄教材或同学的数据，反而容易被发现。

## E.2 综合项目指南 { #e2 }

综合项目是[第 12 章实验 12-2](../chapters/12-management/index.md#12-2)，要求小组为小禾设计工作室完成一份完整的组网方案。

### 分组与分工 { #e21 }

3～4 人一组，推荐的分工如下（每人都要动手配置，组长负责协调和文档汇总）：

| 角色 | 主要负责 |
|---|---|
| 组长 / 规划 | 需求分析、地址规划表、拓扑设计、进度协调、文档汇总 |
| 交换与无线 | VLAN、Trunk、三层交换、无线接入点 |
| 路由与出口 | 静态路由或 OSPF、DHCP、NAT |
| 服务与安全 | Web、DNS、邮件服务器，ACL，SSH，测试验收 |

### 进度安排（建议 3 周） { #e22 }

| 时间 | 任务 | 检查点 |
|---|---|---|
| 第 1 周 | 需求分析、地址规划、拓扑设计；搭建拓扑，完成 VLAN、Trunk、VLAN 间路由 | 地址规划表、拓扑截图；各部门能互通 |
| 第 2 周 | 路由、DHCP、NAT、服务器、无线 | 分店能访问总部；电脑自动获取地址；能用域名访问内部网站 |
| 第 3 周 | ACL、SSH、全面测试，撰写方案文档，准备答辩 | 测试表全部通过；文档完成 |

**每完成一步就保存一个新文件**（如 `xiaohe-v1-vlan.pkt`、`xiaohe-v2-route.pkt`），出了问题可以退回上一个版本。

### 方案文档模板 { #e23 }

```text
小禾设计工作室网络组网方案

第 1 部分 项目概述
    1.1 项目背景（工作室情况）
    1.2 建设目标（列出需求 1～9）
第 2 部分 需求分析
    2.1 用户与部门（人数、位置、将来的增长）
    2.2 应用需求（上网、内部网站、邮件、财务系统……）
    2.3 安全需求
第 3 部分 网络设计
    3.1 拓扑图（Packet Tracer 截图，标注设备名称和接口）
    3.2 VLAN 规划表
    3.3 IP 地址规划表（网段、掩码、网关、DHCP 范围、固定地址）
    3.4 路由设计（静态路由还是 OSPF，为什么）
    3.5 设备选型清单（型号、数量、用途）
第 4 部分 安全设计
    4.1 VLAN 隔离与访客网络
    4.2 ACL 规则表（每条规则的作用）
    4.3 无线安全与设备管理（WPA2/WPA3、SSH、密码策略）
第 5 部分 主要配置说明（每台设备的关键配置，附说明，不必贴全部配置）
第 6 部分 测试报告（测试表，附关键截图）
第 7 部分 总结
    7.1 遇到的问题与解决方法
    7.2 可以改进的地方（如冗余链路、扩张后的调整）
    7.3 小组分工与每人贡献
```

### 评分表 { #e25 }

综合项目满分 100 分，由小组自评、组间互评和教师评分综合得出（建议权重 20% + 20% + 60%）。

| 项目 | 分值 | 评分要点 |
|---|---|---|
| 需求分析与规划 | 15 | 需求完整；地址规划合理（子网大小与人数匹配，留有余量）、没有重叠 |
| 拓扑与配置 | 30 | 拓扑清晰；需求 1～9 全部实现；配置规范（设备命名、接口描述） |
| 安全设计 | 15 | VLAN 隔离、ACL 正确且顺序合理、无线加密、SSH 管理 |
| 测试验收 | 15 | 测试项覆盖全部需求，记录真实，截图清楚 |
| 方案文档 | 15 | 结构完整、图表规范、语言通顺，别人照着文档能看懂网络 |
| 答辩演示 | 10 | 10 分钟内讲清方案，现场演示关键功能，能回答提问 |
| 挑战加分 | 加 5 | 完成实验 12-2 第三档任务之一 |

每人的成绩 = 小组成绩 ×（个人贡献系数，0.8～1.2，由组内互评和教师观察确定）。
