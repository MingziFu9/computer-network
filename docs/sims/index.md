# 交互动画

这些动画都是普通网页，不需要安装任何软件，也不需要联网调用接口，在电脑和手机浏览器上都能打开。每个动画都嵌在对应章节的正文里，也可以从这里单独打开，适合课堂演示。

<!-- sims:start -->
| 章 | 动画 | 你可以做什么 |
|---|---|---|
| 第 1 章 | [电路交换与分组交换](circuit-vs-packet/index.md) | 同样三位用户先后发送一阵一阵的数据，对比电路交换和分组交换谁先送完、线路利用率各是多少 |
| 第 1 章 | [时延计算器](delay-calculator/index.md) | 拖动数据量、发送速率、距离和排队时间，看发送、传播、处理、排队四种时延各占多少 |
| 第 2 章 | [层层装信封](encapsulation/index.md) | 一步步看网页请求在发送方逐层加首部、经过交换机和路由器、在接收方逐层拆开的全过程 |
| 第 2 章 | [协议对号入座](layer-sort/index.md) | 把 20 张协议、数据单位和设备卡片拖进五层模型的对应层，立即判分 |
| 第 3 章 | [编码与调制](encoding/index.md) | 输入一串 0 和 1，同时画出不归零、曼彻斯特、差分曼彻斯特编码和调幅、调频、调相波形 |
| 第 3 章 | [复用](multiplexing/index.md) | 4 路用户共用一条线路，切换频分、时分、统计时分和波分复用，看“频率 × 时间”怎样分配 |
| 第 3 章 | [T568B 线序](rj45-order/index.md) | 把 8 根彩色线排进水晶头 1～8 号引脚，检查对错，对比 T568A 与 T568B |
| 第 4 章 | [冲突域与广播域](collision-domain/index.md) | 在集线器、交换机、路由器之间切换设备，看冲突域和广播域的范围与个数怎样变化 |
| 第 4 章 | [交换机自学习](switch-learning/index.md) | 选发送方和接收方发帧，看交换机怎样记下源地址、转发或泛洪，MAC 地址表怎样一行行填满并老化 |
| 第 5 章 | [VLAN 隔离广播](vlan-isolation/index.md) | 给交换机上的 6 台电脑分配 VLAN，点一台电脑发广播，看广播帧能到达哪些电脑 |
| 第 5 章 | [WiFi 信道](wifi-channel/index.md) | 在 2.4 GHz 频段上给几台路由器选信道，看频谱是否重叠、互相干扰几处 |
| 第 6 章 | [二进制转换器](binary-converter/index.md) | 点亮 8 个小灯看十进制数字变化，输入十进制看对应的二进制，随机出题练习 |
| 第 6 章 | [子网划分计算器](subnet-calculator/index.md) | 输入 IP 地址和前缀长度，逐步显示二进制按位与、网络地址、广播地址和可用范围；输入网段和子网个数，列出每个子网 |
| 第 7 章 | [最短路径](dijkstra/index.md) | 选一个起点路由器，逐步演示最短路径算法怎样由近及远确定每台路由器的距离，最后得到最短路径树 |
| 第 7 章 | [查路由表](route-lookup/index.md) | 输入目的 IP 地址，看路由表中哪几行匹配、最终按最长前缀匹配选中哪一行；可增删路由 |
| 第 8 章 | [ARP 问路](arp/index.md) | 逐步演示 ARP 请求广播、响应单播和 ARP 缓存的更新，打开开关看攻击者怎样用伪造响应冒充网关 |
| 第 8 章 | [DHCP 四步](dhcp/index.md) | 新电脑接入网络，逐步演示 DHCP 发现、提供、请求、确认四个报文和地址池的变化，并对比两台服务器、服务器关机两种情形 |
| 第 8 章 | [NAT 转换表](nat-table/index.md) | 内网多台电脑共享一个公网地址访问外网，看端口地址转换怎样改写源地址和端口、回复怎样查表送回、外网主动访问为什么不通 |
| 第 9 章 | [三次握手与四次挥手](handshake/index.md) | 逐帧观看一条真实 TCP 连接的建立、数据传输和释放，看每个报文段的标志位、序号、确认号和双方连接状态 |
| 第 9 章 | [滑动窗口与拥塞控制](sliding-window/index.md) | 调整窗口、让报文段丢失，看窗口怎样滑动和超时重传；设置门限、触发超时和 3 个重复确认，画出拥塞窗口变化曲线 |
| 第 10 章 | [输入网址之后](after-url/index.md) | 逐步回放浏览器访问一个网站的全过程：解析网址、ARP、DNS、TCP 三次握手、HTTP 请求与响应、断开连接，看每一步用哪一层的什么协议 |
| 第 10 章 | [DNS 查询之旅](dns-journey/index.md) | 逐步看一次域名查询问了哪些服务器、每台服务器怎样回答，对比递归和迭代两种方式，再看缓存怎样让查询一步完成 |
| 第 11 章 | [对称与非对称加密](crypto/index.md) | 用同一把密钥加密解密，体会密钥分发的难题；用公钥加密、私钥解密；用私钥签名、公钥验证，改动文件后看验证失败 |
| 第 11 章 | [防火墙规则匹配](firewall-acl/index.md) | 选择数据包的源、目的和服务，看它怎样从上到下逐条与 ACL 规则比较，第一条匹配的规则决定放行或拒绝；调整规则顺序，看结果怎样变化 |
| 第 11 章 | [钓鱼识别闯关](phishing-quiz/index.md) | 10 封虚构的邮件和短信，判断是可信还是钓鱼，看解析学会“五看”：发件人、链接域名、紧迫感、索要信息、附件 |
