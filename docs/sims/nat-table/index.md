## 教学说明

**学习目标**

1. 能说出 PAT 在请求和回复两个方向上分别改写了什么（理解）；
2. 能根据 NAT 转换表判断回复交给哪台内网主机（应用）；
3. 能解释外网主动访问内网为什么不通（理解）。

**画面与操作**

- 选择内网电脑和要访问的外网服务，点“发出请求”：左侧对比数据报进出路由器时的地址和端口（被改写的部分标黄），右侧转换表新增一行；
- 小林和阿美恰好使用同一个源端口 51001，第二个访问时路由器自动改用 51002，演示端口冲突的处理；
- “服务器回复”演示查表把目的地址和端口改回；“外网主动访问内网”演示无表项时被丢弃。

**数据来源**：按 PAT 规则在浏览器中模拟。公网地址 198.51.100.2 与实验 8-2 一致，属于文档专用地址段。

**课堂用法建议**

1. 依次让三台电脑访问网站，再让学生根据表格回答“发往 198.51.100.2:51002 的回复交给谁”；
2. 联系实验 8-2 中 `show ip nat translations` 的 Inside local / Inside global 两列。
