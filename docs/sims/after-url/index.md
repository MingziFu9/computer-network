## 教学说明

**学习目标**

1. 能按顺序说出从输入网址到看到网页的主要步骤（记忆）；
2. 能说出每一步用到的协议，以及各层首部中的关键地址和端口（理解）；
3. 能解释为什么以太网的目的地址是网关、而 IP 的目的地址是服务器（分析）。

**画面与操作**

- 上方是电脑、网关和服务器，彩色圆点表示正在传送的报文，颜色和标签表示协议（ARP、DNS、TCP、HTTP）；
- 左下说明这一步发生了什么，右下按“应用层—运输层—网络层—链路层—物理层”列出这一步的封装内容，没有用到的层留空；
- 可以逐步点击，也可以“自动播放”。

**数据来源**：12 个步骤对应 `labs/data/pcap/web_visit.pcap` 的第 1～18 帧，地址、MAC 地址、端口、序号、数据长度均用 tshark 从该文件读出。

**课堂用法建议**

1. 播放前先让学生按顺序写出自己认为的步骤，播放后对照修改；
2. 停在 DNS 查询这一步，让学生说出以太网目的 MAC 为什么是网关的；
3. 与实验 10-1、9-1 配合，在 Wireshark 中打开同一个抓包文件逐帧对照。
