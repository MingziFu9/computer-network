## 教学说明

**学习目标**

1. 能识别不归零、曼彻斯特、差分曼彻斯特编码的波形（理解、应用）；
2. 能说出调幅、调频、调相分别改变载波的哪个特征（理解）。

**画面与操作**

- 输入最多 12 位比特串，点“画出来”，六行波形同时更新；
- 点任意一位，该列高亮，下方逐行说明这一位在每种波形中的样子；
- “一长串 0 / 1”预设用来说明不归零编码的同步问题。

**约定**：曼彻斯特编码按本书（IEEE 802.3）约定，码元中间向上跳为 1、向下跳为 0；差分曼彻斯特编码码元开始处有跳变为 0、无跳变为 1，假定第一个码元之前线路为高电平。考试题给出不同约定时以题目为准。

**课堂用法建议**

1. 先让学生在纸上画课后第 17 题（1 0 1 1 0）的曼彻斯特波形，再点预设核对；
2. 点“一长串 1”，比较三种编码，引出“自带同步”的概念。
