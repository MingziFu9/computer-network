## 教学说明

**学习目标**

1. 能说出最短路径算法“每次确定一个距离最小的节点”的思路（理解）；
2. 能按表格一步步算出小型网络中的最短路径（应用）。

**画面与操作**

- 5 台路由器、7 条链路，默认代价与 7.4.3 节例题相同；
- 点任一路由器设为起点（蓝色）；“下一步”每次确定一台路由器（绿色），本步距离被更新的路由器标黄，下方文字写出比较过程；“一次算完”直接给出结果；
- 点链路上的代价数字可以修改，输入 0 表示链路断开，修改后自动从头计算；
- 右侧距离表显示每台路由器的距离、上一站和最短路径，绿色粗线是最短路径树。

**数据来源**：在浏览器中运行最短路径算法。默认例题从 R1 出发的结果为 R2 = 2、R3 = 3、R4 = 5、R5 = 8，与教材表格一致。

**课堂用法建议**

1. 让学生先在纸上完成 7.4.3 节的表格，再逐步点“下一步”核对；
2. 把 R2–R3 改为 0（断开），观察 R1 到 R3、R4 的路径怎样变化，联系实验 7-2 中断开链路后 OSPF 自动改道。
