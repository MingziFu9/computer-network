## 教学说明

**学习目标**

1. 能按 T568B 标准排出网线线序（应用）；
2. 能说出 T568A 与 T568B 的区别，以及直通线和交叉线的含义（理解）。

**画面与操作**

- 点下方的线，它会排进下一个空引脚；点已排的引脚把线取回；
- “检查”后正确的引脚显示绿框、错误的显示红框；“看答案”直接显示标准线序；
- 切换 T568A / T568B 两种标准练习。

**数据来源**：线序按 TIA/EIA-568 标准，与教材 3.4.1 节表格一致。

**课堂用法建议**

1. 发真实网线和水晶头前，先让学生在动画里排对一次；
2. 排完 T568B 再排 T568A，让学生自己找出“1↔3、2↔6 互换”的规律。
