## 教学说明

**学习目标**

1. 能根据 IP 地址和前缀长度求出网络地址、广播地址和可用范围（应用）；
2. 能完成等长子网划分并列出每个子网（应用）。

**画面与操作**

- “算一个地址”页：输入 IP 地址、选择前缀长度（/8～/30），第 1 步用颜色区分网络位和主机位，显示按位与的过程；第 2 步列出掩码、网络地址、广播地址、可用范围、可用主机数、地址类别和是否私有，并给出“块大小”快速算法的提示；
- “划分子网”页：输入网段、前缀和要分成的子网个数（2～64），显示借位数、新前缀、掩码和每个子网的范围；
- 预设按钮对应教材例题和实验 6-1 的练习题。

**数据来源**：在浏览器中按位运算得出，结果与实验 6-1 的 Python `ipaddress` 程序一致（编者用 192.168.8.100/27、10.1.1.200/28、172.20.5.8/12 核对过）。

**课堂用法建议**

1. 先让学生手算，再用计算器核对，不要直接看答案；
2. 在“划分子网”页依次选 2、4、8 个子网，引导学生发现“子网数翻倍，每个子网的地址数减半”。
