## 教学说明

**学习目标**

1. 能说出集线器、交换机、路由器对冲突域和广播域的影响（理解）；
2. 能数出给定拓扑中冲突域和广播域的个数（分析）。

**画面与操作**

- 拓扑固定为“中间一台设备 + 左右两台设备 + 各 3 台电脑”；点设备切换类型：中间可选集线器、交换机、路由器，两边可选集线器、交换机；
- 每种颜色的连线代表一个冲突域，虚线大框代表一个广播域，下方显示个数和原因；
- 五个预设对应常见考题情形。

**数据来源**：按“集线器合并冲突域、交换机每口一个冲突域、路由器每口一个广播域”的规则计算。五个预设的结果：全集线器 1/1，集线器 + 中间交换机 2/1，全交换机 8/1，交换机 + 中间路由器 8/2，左集线器 + 路由器 + 右交换机 5/2（冲突域/广播域）。

**课堂用法建议**

1. 先出题让学生手数，再点预设核对；
2. 强调设备之间的连线也算一个冲突域，这是学生最容易漏数的地方。
