## 教学说明

**学习目标**

1. 能把 0～255 的十进制数和 8 位二进制数互相转换（应用）；
2. 能认出子网掩码中常用的值（128、192、224、240、248、252、254、255）（记忆）。

**画面与操作**

- 8 个灯从左到右代表 128、64、32、16、8、4、2、1，点一下切换亮灭，下方实时显示二进制、十进制和加法算式；
- 输入十进制数点“转成二进制”，或点“掩码常用值”按钮直接显示；遇到前面全 1、后面全 0 的值会提示它可以出现在子网掩码中；
- “练一练”随机出题：十进制转二进制时点亮正确的灯即判对，二进制转十进制时输入答案提交。

**数据来源**：在浏览器中按位权计算。

**课堂用法建议**

1. 课前 5 分钟用“练一练”抢答热身；
2. 依次点 128～255 的掩码常用值，让学生总结“每多一个 1 加多少”的规律。
