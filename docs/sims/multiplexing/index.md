## 教学说明

**学习目标**

1. 能区分频分、时分、波分、码分复用的划分方式（理解）；
2. 能解释统计时分复用为什么比时分复用利用率高（分析）。

**画面与操作**

- 横轴为时间（8 个时间段），纵轴为频率或波长；色块表示分给某个用户并真正用上的资源，灰色虚框表示分出去却空着的资源；
- 四个按钮切换复用方式，勾选框控制哪些用户有数据要发；
- 下方显示分配了多少块、用上多少块和利用率。

**数据来源**：每个用户在 8 个时间段中是否有数据，是编者预设的固定模式（四人分别有 6、5、5、6 段有数据），用于演示。全部勾选时频分、时分利用率为 22/32 ≈ 69%，统计时分不浪费时隙。码分复用难以用这种图表示，课堂上用“不同语言同时说话”的比喻讲解。

**课堂用法建议**

1. 在时分复用下取消勾选两个用户，让学生说出浪费了多少；再切到统计时分对比；
2. 联系 1.4.3 节分组交换，说明统计时分复用与“按需共享”的关系。
