## 教学说明

**学习目标**

1. 能按“看线和灯 → ipconfig → ping 127.0.0.1 → ping 网关 → ping 外网 IP → nslookup”的顺序排查（应用）；
2. 能根据命令结果判断故障出在哪一层（分析）；
3. 能区分“请求超时”“无法访问目标网络”“传输失败”等提示的含义（理解）。

**画面与操作**

- 每关给出一个故障现象；左侧点击排查手段，黑色窗口中显示对应的结果；
- 右侧选择故障原因，至少执行一个排查手段后才能作答；答完显示正误、用了几个排查手段和详细解析；
- 5 关依次为：网线松动、DHCP 获取失败、默认网关错误、DNS 故障、分店路由器缺少路由。

**数据来源**：故障场景按小禾设计工作室的地址规划编写（设计部 192.168.8.0/26，网关 192.168.8.1，DNS 192.168.8.130，分店 192.168.9.0/24）。命令结果是按 Windows 中文版格式编写的**输出格式示意**，具体数值以实际为准。

**课堂用法建议**

1. 让学生比赛：谁用最少的排查手段答对全部 5 关；
2. 每关结束后请学生说出“哪一条结果让你排除了其他选项”；
3. 闯关后进入实验 12-1，在 Packet Tracer 中互相设置真实故障。
