## 教学说明

**学习目标**

1. 能说出三次握手和四次挥手每一步的标志位（记忆）；
2. 能根据“确认号 = 对方序号 + 数据长度（SYN、FIN 各算 1）”算出确认号（应用）；
3. 能说出连接过程中双方的主要状态，解释 TIME-WAIT 的作用（理解）。

**画面与操作**

- 左侧是时序图，每点一次“下一步”多画一个报文段；颜色区分 SYN（蓝）、带数据（橙）、纯确认（绿）、FIN（红）；
- 右侧显示当前报文段的标志位、序号、确认号、数据长度和内容，以及客户端、服务器此刻的连接状态；
- 勾选“显示真实序号”，序号和确认号换成抓包中的真实值（相对序号 + 初始序号）。

**数据来源**：14 个报文段的方向、标志位、序号、确认号和数据长度与 `labs/data/pcap/tcp_udp_chat.pcap` 第 1～14 帧一致（用 tshark 读出）。连接状态按 TCP 状态机标注，抓包文件本身不包含状态。

**课堂用法建议**

1. 每到一个确认报文，先暂停，让学生算出确认号再点“下一步”核对；
2. 停在第 9 帧，让学生说出为什么服务器没有单独回确认（捎带确认）；
3. 与实验 9-1 配合：学生在 Wireshark 中找到同样的 14 帧，对照本动画填写实验表格。
