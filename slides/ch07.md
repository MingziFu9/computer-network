# 7.1 路由器做什么

## 转发与路由选择
| 工作 | 做什么 | 比喻 |
|---|---|---|
| **转发** | 查表，从合适接口送出 | 分拣员看地址 |
| **路由选择** | 建立和更新路由表 | 规划分拣规则 |

## 路由器 vs 交换机
| | 交换机 | 路由器 |
|---|---|---|
| 层次 | 数据链路层 | 网络层 |
| 依据 | 目的 MAC | 目的 IP |
| 查的表 | MAC 地址表 | 路由表 |
| 广播 | 转发 | **不转发** |

## 一路上什么变、什么不变（考点）
- 源 IP、目的 IP：**不变**
- 源 MAC、目的 MAC：**每段都变**
- MAC 管一段路，IP 管全程
- 电脑发往其他网段 → 交给**默认网关**

# 7.2 路由表

## 路由表长什么样
| 目的网络 | 下一跳 | 出接口 |
|---|---|---|
| 192.168.8.0/26 | 直接交付 | Gi0/0 |
| 10.0.12.0/30 | 直接交付 | Gi0/1 |
| 192.168.9.0/24 | 10.0.12.2 | Gi0/1 |
| **0.0.0.0/0** | 203.0.113.1 | Gi0/2 |

::: notes
0.0.0.0/0 是默认路由：表里找不到更具体的路，就往这里送，一般指向运营商。小单位的出口路由器通常只要直连路由加一条默认路由。
:::

## 最长前缀匹配（考点）
- 多条都匹配，选**前缀最长**的
- 去 192.168.9.200：匹配 /24、/25、默认
  - 选 /25 → 下一跳 10.0.13.2
- 去 192.168.9.20：不在 .128/25
  - 选 /24 → 下一跳 10.0.12.2

::: notes
比喻：越具体的地址越优先，“北京市海淀区”比“北京市”更具体。默认路由 /0 最短，永远最后才用。
:::

# 7.3 静态路由

## 手工写一条路
```text
ip route 目的网络 子网掩码 下一跳
R1(config)#ip route 192.168.9.0 255.255.255.0 10.0.12.2
R2(config)#ip route 0.0.0.0 0.0.0.0 10.0.12.1
```

::: notes
R1 写去分店的路由，R2 写一条默认路由指回总部。思科路由器接口默认关闭，配好地址要 no shutdown。
:::

## 路由要“来回”都有（考点）
- R1 有去分店的路，数据能过去
- R2 不知道怎么回总部 → 回不来
- **两边都要配**
- 静态路由：简单、安全；网络一变要手工改

# 7.4 动态路由

## RIP 与 OSPF
| | RIP | OSPF |
|---|---|---|
| 类型 | 距离向量 | 链路状态 |
| 交换对象 | 相邻路由器 | 通告全网 |
| 度量 | 跳数，**最大 15** | 代价（带宽） |
| 收敛 | 慢 | 快 |

::: notes
RIP 像“听邻居说的”，16 跳表示不可达，只适合小网络。OSPF 像每台路由器都有一张全城地图，自己算最短路径。实验 7-2 用 OSPF 让三台路由器自动找路。
:::

## 算一算：从 R1 出发的最短路径
| 步骤 | 确定 | R2 | R3 | R4 | R5 |
|---|---|---|---|---|---|
| 开始 | R1(0) | 2 | 5 | ∞ | ∞ |
| 1 | R2(2) | ✓ | **3** | 9 | ∞ |
| 2 | R3(3) | ✓ | ✓ | **5** | 11 |
| 3 | R4(5) | ✓ | ✓ | ✓ | **8** |

::: notes
每一步在未确定的里选代价最小的确定下来，再用它更新邻居。结论：R1 到 R3 走 R1→R2→R3（代价 3）比直连（5）还短。闭卷只要求按表格算出结果。
:::

## 自治系统与 BGP（了解）
- 自治系统：一个运营商、一个大单位
- 内部用 OSPF 等
- 自治系统之间用 **BGP**
- 多种来源时按可信度选：直连 > 静态 > OSPF > RIP

# 7.5 三层交换机与 VLAN 间路由

## 三层交换机：每个 VLAN 一个网关
```text
Switch(config)#ip routing
Switch(config)#interface vlan 10
Switch(config-if)#ip address 192.168.8.1 255.255.255.192
Switch(config-if)#interface vlan 20
Switch(config-if)#ip address 192.168.8.65 255.255.255.224
```

::: notes
接第 5 章：VLAN 隔离后要互通，用三层交换机的虚拟接口（SVI）做各 VLAN 的网关。电脑的默认网关填对应 SVI 的地址。比单臂路由性能好。
:::

# 7.6 用 tracert 看路

## tracert 的原理
- 依次发 TTL = 1、2、3……的包
- 每一跳路由器 TTL 减到 0，回“超时”
- 一行一跳，三次往返时间
- `* * *`：该路由器不回应，不一定断

# 7.7 常见问题与 AI 与网络

## 本章常见问题对照
| 现象 | 原因 |
|---|---|
| 单向配了路由不通 | 去得了回不来 |
| 通网关不通其他网段 | 没配网关或缺路由 |
| 接口配了 IP 还是 down | 要 `no shutdown` |
| 第一次 ping 前一两个超时 | 正在 ARP |

## AI 与网络：帮网络“看路况”
- 像导航软件避开拥堵
- **集中控制**：控制器掌握全网拓扑和流量
- AI 预测流量，提前调整路径
- 人负责设定目标和审核
