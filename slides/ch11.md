# 11.1 网络安全要保护什么

## 三个基本目标（考点）
| 目标 | 被破坏的例子 | 手段 |
|---|---|---|
| **机密性** | HTTP 登录密码被抓包 | 加密、访问控制 |
| **完整性** | 邮件里收款账号被改 | 哈希、签名 |
| **可用性** | 网站被大量请求冲垮 | 备份、冗余、抗 DDoS |

## 常见威胁
| 威胁 | 破坏 |
|---|---|
| 钓鱼 | 机密性 |
| 病毒与木马 | 机密性、完整性 |
| 勒索软件 | 可用性 |
| DDoS | 可用性 |
| 中间人攻击 | 机密性、完整性 |

# 11.2 密码学的直观

## 对称与非对称加密
| | 对称 | 非对称 |
|---|---|---|
| 密钥 | 同一把 | 公钥、私钥一对 |
| 速度 | 快 | 慢 |
| 分发 | 困难 | 公钥可公开 |
| 算法 | AES、SM4 | RSA、SM2 |

::: notes
给禾姐发机密文件，用禾姐的公钥加密，只有禾姐的私钥能解开。实际使用常把两者结合：用非对称加密交换对称密钥，再用对称加密传大量数据。
:::

## 哈希、数字签名与证书
- **哈希**：数据的指纹，改一点全变，不可逆
- **数字签名**：发送方**私钥**签，接收方用**公钥**验
- **数字证书**：CA 签名证明“这个公钥属于谁”
- 国产商用密码：SM2、SM3、SM4

# 11.3 HTTPS 为什么安全

## HTTPS = HTTP + TLS
- 端口 **443**
- 抓包对比 `http_vs_https.pcap`
  - HTTP：密码明文可见
  - HTTPS：只看到 TLS 握手和密文
- 仍能看到访问的域名（SNI）

::: notes
抓包里第 10 帧 POST 能直接看到 user=xiaolin&password=...；第 26 帧 Client Hello 中 SNI 是 www.xiaohe.com；第 28 帧 Server Hello 协商出 TLS 1.3。所以 HTTPS 下抓包者看不到内容，但能看到访问的是哪个网站（判断题第 14 题）。
:::

## TLS 握手的直观
!mermaid 1
- 证书：确认对方身份，防中间人
- 密钥交换：商定对称密钥
- 对称加密 + 消息认证

## 有锁 ≠ 网站可信
- 锁只说明**通信加密**、证书属于该域名
- 钓鱼网站也能申请证书
- 要看清**域名**是否正确
- “连接不是私密连接”：证书有问题，别继续

# 11.4 防火墙与 ACL

## 三类防火墙
| 类型 | 检查什么 |
|---|---|
| 包过滤 | IP、协议、端口 |
| 状态检测 | 再记住连接状态 |
| 应用层 | 网址、内容 |

## ACL 的规则（考点）
- **从上到下**逐条比较，**第一条匹配**生效
- 最后有一条看不见的 **deny any**
- 标准 ACL 1～99：只看源 IP，靠近目的
- 扩展 ACL 100～199：IP、协议、端口，靠近源

## 通配符掩码
| 网段 | 子网掩码 | 通配符掩码 |
|---|---|---|
| 192.168.8.64/27 | 255.255.255.224 | **0.0.0.31** |
| 192.168.8.0/26 | 255.255.255.192 | 0.0.0.63 |
| 一台主机 | — | `host` |
| 任意 | — | `any` |

::: notes
通配符掩码 = 255.255.255.255 − 子网掩码，0 表示要比较，1 表示不管。
:::

## 保护财务服务器：ACL 110
```text
access-list 110 permit ip 192.168.8.64 0.0.0.31 host 192.168.8.131
access-list 110 deny   ip any host 192.168.8.131
access-list 110 deny   ip 192.168.8.96 0.0.0.31 any
access-list 110 permit tcp any host 192.168.8.130 eq 80
access-list 110 permit icmp any any
```

::: notes
① 财务部可访问财务服务器 ② 其他人不能 ③ 访客不能进服务器区 ④ 大家能浏览内部网站 ⑤ 允许 ping。应用在三层交换机 VLAN 40 接口的 out 方向（实验 11-2）。
:::

## IDS、IPS 与 VPN
- **入侵检测系统**（IDS）：发现可疑，报警
- **入侵防御系统**（IPS）：当场拦截
- **VPN**：在互联网上建加密隧道
  - 出差员工访问内部网站

# 11.5 安全习惯与法律

## 个人与小单位的安全习惯
- 强口令、不重复，开**双因素认证**
- 及时更新系统和路由器固件
- **3-2-1** 备份
- 小心公共 WiFi
- 钓鱼“五看”：发件人、域名、紧迫感、索要信息、附件

| 法律 | 施行 |
|---|---|
| 网络安全法 | 2017-06-01（2025 年修正，2026-01-01 施行） |
| 数据安全法 | 2021-09-01 |
| 个人信息保护法 | 2021-11-01 |
| 等级保护 | GB/T 22239—2019 |

# 11.7 常见问题与 AI 与网络

## 本章常见问题对照
| 现象 | 原因 |
|---|---|
| “连接不是私密连接” | 证书有问题 |
