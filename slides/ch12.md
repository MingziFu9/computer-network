# 12.1 网络管理做什么

## 网络管理的五大功能
| 功能 | 工作室里的例子 |
|---|---|
| **故障**管理 | DNS 服务器没开机 |
| **配置**管理 | 改配置前先备份 |
| **性能**管理 | 视频会议时出口跑满 |
| **安全**管理 | 财务服务器只许财务部访问 |
| **计费**管理 | 运营商按流量计费 |

::: notes
简称 FCAPS。课后练习第 1 题：定期备份配置、记录修改，属于配置管理。
:::

## SNMP：设备的“体检报告”
- **管理站**：定期询问各设备
- **代理**：设备上回答询问的程序
- **MIB**：可以查询哪些信息
- 查询 UDP **161**，陷阱 UDP **162**
- 比喻：护士站和病房监护仪

## 日志与远程管理
- 设备日志集中收集，便于追查
- 远程管理用 **SSH**，不用 Telnet
- 改完配置要保存
  - `copy running-config startup-config`

# 12.2 故障排查方法（考点）

## 排查的基本思路
- 先问清**影响范围**：一个人还是大家？
- **由下往上**：线 → 地址 → 网关 → 路由 → DNS → 应用
- 由上往下：怀疑某个应用时
- **分段排查**：ping、tracert 找断在哪段

## 六步法
| 步 | 命令 | 不正常说明 |
|---|---|---|
| ① | 看网线、指示灯 | 物理层问题 |
| ② | `ipconfig` | 169.254：DHCP 没分到 |
| ③ | `ping 127.0.0.1` | 本机协议问题 |
| ④ | `ping 网关` | 本地网络问题 |
| ⑤ | `ping 外网 IP` | 出口问题 |
| ⑥ | `nslookup 域名` | DNS 问题 |

::: notes
六步都正常网页还打不开，就是应用层问题：代理设置、网站故障、被防火墙或 ACL 拦截。ping 失败提示：“请求超时”是发出去没回音；“无法访问目标主机”是路上有设备说找不到路。
:::

## 设备上的检查命令
| 命令 | 看什么 |
|---|---|
| `show ip interface brief` | 接口地址和状态 |
| `show vlan brief` | VLAN 和接口 |
| `show interfaces trunk` | Trunk |
| `show ip route` | 路由表 |
| `show running-config` | 当前配置 |

## 动手：故障排查闯关
!sim troubleshoot
- 5 关，每关一个故障
- 选命令、看结果、找原因

## 常见故障案例
| 现象 | 原因 |
|---|---|
| 媒体已断开连接 | 网线松了、坏了 |
| 169.254.x.x | DHCP 没分到 |
| 同网段通、其他网段不通 | 网关错误 |
| 外网 IP 通、网页打不开 | DNS 故障 |
| 部门之间不通 | 缺路由、没开 `ip routing` |

# 12.3 网络优化与新技术

## 网络优化（了解）
- 找出**带宽瓶颈**，升级或加线路
- 多台 AP 改善 WiFi 覆盖
- **QoS**：带宽不足时视频会议优先
- 定期巡检：实验 12-3 的 Python 小工具

## 新技术一览（了解）
| 技术 | 一句话理解 |
|---|---|
| **SDN** | 控制与转发分离，集中编程管理 |
| 云网络与 VPC | 在云里划分自己的网络 |
| 数据中心网络 | 叶脊结构 |
| 5G | 低时延、大连接 |
| 物联网 | 海量低功耗设备联网 |

::: notes
东数西算：2022 年 2 月启动，8 个算力枢纽节点、10 个数据中心集群。VPC 等云网络内容在《云计算及应用》课讲。
:::

# 12.5 小型网络规划设计

## 规划设计七步
!mermaid 1
- 需求分析 → 拓扑设计 → 地址规划
- 设备选型 → 安全设计
- 测试验收 → 文档交付

## 小禾工作室：全书回顾
| 步骤 | 工作室的答案 |
|---|---|
| 拓扑 | 星形；总部和分店专线（第 1、7 章） |

::: notes

:::

# 12.6 常见问题与 AI 与网络

## 本章常见问题对照
| 现象 | 原因 |
|---|---|
| 不知道从哪查 | 没按顺序，用六步法 |
| ping 不通但网页能开 | 服务器不回应 ping |
| administratively down | 要 `no shutdown` |
| 重启后配置没了 | 没保存 |

## AI 与网络：智能运维 AIOps
- 异常检测与故障预测
- 告警归并与根因分析
- 对话式运维：自然语言问原因
- AI 生成的配置**必须人审核**
- 日志含密码等敏感信息，不能随便上传
