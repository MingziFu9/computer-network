# 4.1 数据链路层要做什么

## 三个基本问题
- **封装成帧**：加首部和尾部，标出边界
- **透明传输**：数据里出现标志也不误判
  - 字节填充（PPP）、零比特填充
- **差错检测**：CRC 校验
- 链路：一段线；数据链路：线 + 协议

::: notes
比喻：快递的一段路。数据链路层只管相邻两个节点之间的这一段，全程怎么走是网络层的事。
:::

## CRC：只发现，不纠正（考点）
- 发送方按数据算出校验码，放在帧尾
- 接收方重算，不一致 → **丢弃**
- 以太网用 CRC-32
- 重传靠上层（如 TCP）
- PPP 也只检错、不重传

# 4.2 以太网与 MAC 地址

## MAC 地址：网卡的“身份证号”
| MAC 地址 | 前 24 位厂商 | 是谁 |
|---|---|---|
| `00:e0:4c:68:01:0a` | Realtek | 小林的电脑 |
| `00:e0:fc:12:34:01` | Huawei | 工作室路由器 |

::: notes
48 位，通常写成 6 组十六进制。前 24 位是厂商代码（OUI），后 24 位是厂商分配的序号。电脑换城市接入，MAC 地址不变，变的是 IP 地址。动手：ipconfig /all 里的“物理地址”。
:::

## 单播、广播、多播
| 类型 | 目的地址 | 谁收下 |
|---|---|---|
| 单播 | 某块网卡 | 只有它 |
| **广播** | `ff:ff:ff:ff:ff:ff` | 所有网卡 |
| 多播 | 一组地址 | 组成员 |

# 4.3 以太网帧格式

## 帧的各个字段
| 字段 | 长度 |
|---|---|
| 目的地址 | 6 字节 |
| 源地址 | 6 字节 |
| **类型** | 2 字节 |
| 数据 | 46～1500 字节 |
| FCS（CRC） | 4 字节 |

::: notes
前导码 8 字节由物理层加，不算帧长。类型字段是上下层的接口：0x0800 IPv4、0x0806 ARP、0x86DD IPv6。数据最长 1500 字节就是 MTU；最短帧长 64 字节 = 14 + 46 + 4。
:::

## 在抓包里认出以太网帧

- 只有 42 字节？抓包时还没加填充和 FCS

# 4.4 共享介质与 CSMA/CD

## CSMA/CD：先听后说，边说边听
| 名字 | 开会比喻 |
|---|---|
| 多点接入 | 大家在一个会议室 |
| 载波监听 | **先听后说** |
| 碰撞检测 | **边说边听**，撞了就停 |
| 退避重传 | 随机等一会再说 |

## 争用期与最短帧长（考点）
- 争用期：信号往返一次，**51.2 μs**
- 51.2 μs × 10 Mbit/s = 512 位 = **64 字节**
- 短于 64 字节的帧可能撞了却不知道
- 今天交换机 + 全双工：**不再需要** CSMA/CD

::: notes
无线局域网也要抢着说话，但无线检测不到碰撞，用的是 CSMA/CA（碰撞避免），第 5 章提一下。
:::

# 4.5 集线器与交换机

## 集线器 vs 交换机
| | 集线器 | 交换机 |
|---|---|---|
| 层次 | 物理层 | 数据链路层 |
| 收到帧 | 所有口发出 | 查表，发到目的口 |
| 带宽 | 共享 | 每口独享 |
| 双工 | 半双工 | 全双工 |

## 冲突域与广播域
| 设备 | 冲突域 | 广播域 |
|---|---|---|
| 集线器 | 不隔离 | 不隔离 |
| 交换机 | **每口一个** | 不隔离 |
| 路由器 | 隔离 | **每口一个** |

::: notes
算一算：交换机接 4 台电脑和 1 台集线器，集线器下 3 台电脑。冲突域 4 + 1 = 5 个；没有路由器，广播域 1 个。
:::

# 4.6 交换机怎样工作

## 自学习：看**源**地址
- 帧进来，记下“源 MAC 在哪个口”
- 表项会**老化**，过一段时间删掉
- 不用手工配置，**即插即用**
- 学源地址，按**目的**地址转发

## 转发、泛洪、过滤
| 情况 | 做法 |
|---|---|
| 查到，在另一个口 | **转发** |
| 查不到，或广播 | **泛洪** |
| 查到，就在进来的口 | **过滤**（丢弃） |

- A 发给 C：表空，泛洪
- C 回 A：已知 A，转发
- 广播：一律泛洪

# 4.7 以太网的发展

## 从 10M 到 800G
| 名称 | 速率 | 用途 |
|---|---|---|
| 100BASE-TX | 100 Mbit/s | 老旧设备 |
| 1000BASE-T | 1 Gbit/s | 办公、家庭 |
| 10G | 10 Gbit/s | 服务器、上联 |
| 25G～800G | 光纤 | 数据中心、AI |

## 交换机指示灯
| 灯 | 含义 |
|---|---|
| 不亮 | 没连上 |
| 常亮绿 | 连通，无数据 |
| 闪烁绿 | 收发数据 |
| 橙色 | 低速或正在启动 |

# 4.8 常见问题与 AI 与网络

## 本章常见问题对照
| 现象 | 原因 |
|---|---|
| 接口灯不亮 | 物理没连通 |
| 橙灯过一会变绿 | 生成树检查环路，等 30 秒 |
| 突然极慢、灯狂闪 | 接成环路，广播风暴 |
| 集线器上一起传很慢 | 共享带宽、碰撞 |

## AI 与网络：更快的以太网
- 上万块 GPU 每一步都要**交换结果**
- 普通以太网：拥挤丢帧，CPU 负担重
- **InfiniBand**：低时延不丢包，较贵
- **RoCE**：在以太网上远程直接读写内存
