# 6.1 网络层与 IP 协议

## 网络层做什么
- 给每个接口一个 **IP 地址**
- 路由器按目的 IP **一站一站转发**
- IP 协议**尽力而为**
  - 不保证送到、不保证顺序
  - 可靠性交给 TCP（第 9 章）

# 6.2 二进制与十进制

## 记住八个数
| 位 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 值 | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |

::: notes
二进制转十进制：把为 1 的位的值加起来，11000000 = 128 + 64 = 192。十进制转二进制：从 128 开始，够减就写 1 并减掉，100 = 64 + 32 + 4 = 01100100。
:::

## 掩码常见值
| 十进制 | 二进制 |
|---|---|
| 128 | 10000000 |
| 192 | 11000000 |
| 224 | 11100000 |
| 240 | 11110000 |
| 248 | 11111000 |
| 252 | 11111100 |

# 6.3 IPv4 地址

## 分类的 IP 地址（考点）
| 类 | 第一组 | 默认掩码 | 可用主机数 |
|---|---|---|---|
| A | 1～126 | 255.0.0.0 | 2²⁴ − 2 |
| B | 128～191 | 255.255.0.0 | 65 534 |
| C | 192～223 | 255.255.255.0 | 254 |
| D | 224～239 | — | 多播 |
| E | 240～255 | — | 保留 |

::: notes
32 位，点分十进制，网络号 + 主机号两级结构。IP 地址标识的是接口，路由器每个接口一个地址。课后练习第 2 题：150 在 128～191，B 类。
:::

## 特殊地址（考点）
| 地址 | 含义 |
|---|---|
| 主机号全 0 | 网络地址 |
| 主机号全 1 | 广播地址 |
| 127.x.x.x | 环回，测试本机 |
| 0.0.0.0 | 本机 / 默认路由 |
| 255.255.255.255 | 受限广播 |

## 私有地址
| 范围 | CIDR |
|---|---|
| 10.0.0.0～10.255.255.255 | 10.0.0.0/8 |
| 172.16.0.0～172.31.255.255 | 172.16.0.0/12 |
| 192.168.0.0～192.168.255.255 | 192.168.0.0/16 |

::: notes
私有地址可以在各单位内部重复使用，互联网上的路由器不转发，上网靠 NAT（第 8 章）。动手：ipconfig 看自己的地址是不是私有地址。
:::

# 6.4 子网掩码与 CIDR

## 掩码与斜线记法
- 掩码：网络号位为 1，主机号位为 0
- /26 = 26 个 1 = 255.255.255.**192**
- 主机数 = **2ᵐ − 2**（m 是主机位数）
- **块大小** = 256 − 掩码最后一组

## 算一算：192.168.8.100/27
- 块大小 256 − 224 = **32**
- 100 落在 96～127
- 网络地址 **.96**，广播地址 **.127**
- 可用 **.97～.126**，共 **30** 个

::: notes
二进制做法：100 = 011|00100，224 = 111|00000，按位与得 011|00000 = 96。块大小法更快：找不大于 100 的 32 的倍数。
:::

## 两台电脑在同一网段吗
- 192.168.8.70/27 和 192.168.8.100/27
- 70 → 网络 .64；100 → 网络 .96
- **不同网段**，要经过路由器
- 都改成 /24：网络都是 .0，同一网段

# 6.5 子网划分

## 等长划分：借位
- 192.168.8.0/24 平均分 4 个：借 **2** 位
- /26，掩码 .192，块大小 64，可用 62
- 子网：.0、.64、.128、.192
- 每个子网要 N 台：找最小 m 使 2ᵐ − 2 ≥ N

## 变长划分：为工作室规划
| 部门 | 需要 | 前缀 | 子网 | 可用 |
|---|---|---|---|---|
| 设计部 | 50 | /26 | .0/26 | .1～.62 |
| 财务部 | 20 | /27 | .64/27 | .65～.94 |
| 访客区 | 20 | /27 | .96/27 | .97～.126 |
| 服务器 | 5 | /29 | .128/29 | .129～.134 |

::: notes
方法（考点）：先给最大的部门；每个子网的网络地址必须是自己块大小的整数倍。习惯上第一个可用地址作网关：.1、.65、.97、.129。剩下 .136～.255 留作扩展。这套地址贯穿第 7～12 章。
:::

# 6.6 IPv4 数据报的格式

## 首部关键字段
| 字段 | 作用 |
|---|---|
| 版本 | 4 或 6 |
| 总长度 | 最大 65 535 字节 |
| **TTL** | 每过一个路由器减 1，到 0 丢弃 |
| **协议** | 6 = TCP，17 = UDP，1 = ICMP |
| 源、目的地址 | 各 32 位 |

::: notes
TTL 防止数据报在环路里无限转圈；ping 显示的 TTL 可以粗略看出经过了几跳。分片（了解）：数据报大于 MTU 时切开，靠标识、标志、片偏移在目的主机重组。
:::

# 6.7 IPv6

## IPv6 地址怎么写
- **128 位**，8 组十六进制，冒号分隔
- 每组开头的 0 可省略
- 连续全 0 组用 `::`，**只能用一次**
- `2001:db8::1428:57ab`

## IPv6 地址类型
| 类型 | 写法 | 相当于 IPv4 |
|---|---|---|
| 全球单播 | 2 或 3 开头 | 公网地址 |
| 链路本地 | `fe80::` | 169.254.x.x |
| 环回 | `::1` | 127.0.0.1 |
| 文档专用 | `2001:db8::/32` | 203.0.113.0/24 |
