# 5.1 为什么要划分 VLAN

## VLAN：一台交换机“切”成几台
| 作用 | 说明 |
|---|---|
| **隔离广播** | 广播只在本 VLAN 内 |
| 增强安全 | 不同 VLAN 默认不通 |
| 灵活管理 | 按部门而不是按位置 |
| 节省成本 | 一台当几台用 |

::: notes
比喻：一栋楼里的几家公司，共用一栋楼但各有各的门。考点：VLAN 隔离的是广播域，不是冲突域（冲突域交换机本来就按接口隔离了）。
:::

# 5.2 Access 口、Trunk 口与 802.1Q

## Access 口与 Trunk 口
- **Access 口**：只属于一个 VLAN，接电脑
  - 发给电脑的帧**不带**标签
- **Trunk 口**：多个 VLAN 共用一根线
  - 交换机之间、交换机到路由器
  - 帧带上 **802.1Q 标签**

## 802.1Q 标签：多了 4 字节
| 字段 | 长度 | 含义 |
|---|---|---|
| 标签类型 | 2 字节 | 固定 `0x8100` |
| 优先级等 | 4 位 | 语音、视频优先 |
| **VID** | 12 位 | VLAN 号 **1～4094** |

::: notes
抓包文件 vlan_trunk.pcap（12 帧）由编者用 scapy 按 802.1Q 标准构造：设计部（VLAN 10）、财务部（VLAN 20）各一台电脑 ping 另一层楼的同事。实验 5-2 用 Wireshark 打开，还可以用 lab5_2_vlan_count.py 数每个 VLAN 的帧数。
:::

## 配置 VLAN 三步
```text
Switch(config)# vlan 10
Switch(config-vlan)# name Design
Switch(config)# interface fa0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config)# interface gig0/1
Switch(config-if)# switchport mode trunk
```

::: notes
查看：show vlan brief 看每个 VLAN 有哪些接口；show interfaces trunk 看 Trunk。华为命令见附录 C.2。
:::

## 不同 VLAN 之间怎样通信
- VLAN 隔离后，要互通得经过**三层**
- **单臂路由**：路由器子接口 + Trunk
- **三层交换机**：每个 VLAN 一个虚拟接口作网关
- 第 7 章动手配置

# 5.4 冗余、环路与生成树

## 多连一根线，网络反而瘫痪
- 交换机之间成环
- 广播帧不停绕圈：**广播风暴**
- MAC 地址表反复变化
- 全网极慢，指示灯狂闪

## 生成树：自动堵住多余的路
- STP 阻塞部分接口，**逻辑上无环**
- 正在用的链路坏了，阻塞口**自动启用**
- 比喻：小区的备用门平时锁着
- 链路聚合：几根线捆成一根用（了解）

# 5.5 无线局域网

## WiFi 的代际
| 代号 | 标准 | 频段 |
|---|---|---|
| WiFi 4 | 802.11n | 2.4 / 5 GHz |
| WiFi 5 | 802.11ac | 5 GHz |
| WiFi 6 | **802.11ax** | 2.4 / 5（/ 6）GHz |
| WiFi 7 | 802.11be | 2.4 / 5 / 6 GHz |

## 2.4 GHz 与 5 GHz
| | 2.4 GHz | 5 GHz |
|---|---|---|
| 覆盖、穿墙 | 远、强 | 近、弱 |
| 速率 | 较低 | 较高 |
| 干扰 | 大 | 小 |
| 互不重叠信道 | **1、6、11** | 多 |

## 动手：信道撞车
!sim wifi-channel
- 周围路由器都挤在同一信道？
- 2.4 GHz 选 1、6、11 中最空闲的

## CSMA/CA：无线怎样排队说话
- 无线**检测不到**碰撞
- 先听，空闲再等一段**随机**时间
- 收到数据要回**确认帧**
- 有线 CSMA/CD，无线 CSMA/CA（考点）

# 5.6 无线组网与安全

## 无线路由器、AP 与 AC
| 设备 | 作用 |
|---|---|
| 无线路由器 | 路由 + 交换 + AP，家庭 |
| AP | 只负责无线接入 |
| AC | 统一管理很多 AP |
| Mesh | 几台路由器组成一个大网 |

## 加密方式
| 方式 | 建议 |
|---|---|
| 开放、WEP、WPA | **不要用** |
| WPA2 | 可以用，配强密码 |
| WPA3 | 首选 |

::: notes
常见误区：隐藏 SSID 不能代替加密；关闭 WPS；访客用访客网络；改掉路由器出厂管理密码。
:::

# 5.7 常见问题与 AI 与网络

## 本章常见问题对照
| 现象 | 原因 |
|---|---|
| 同部门电脑不通了 | 接口进了不同 VLAN |
| 两台交换机同 VLAN 不通 | 中间不是 Trunk |
| 不同 VLAN 不通 | 正常，要三层互通 |
| 多连一根线全网慢 | 环路，广播风暴 |

## AI 与网络：给智能设备单独一个网络
- 摄像头、音箱、门锁越来越多
- 放进**单独的网络**：访客网络、单独 VLAN
- 一台被攻破，也碰不到电脑和文件
- AI 帮无线控制器自动选信道、调功率
