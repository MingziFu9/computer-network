# 课件底稿

每章一个 `chNN.md`，由 `python tools/make_slides.py build NN` 排版成 `build/课件/第NN章 章名.pptx`（16:9，系列统一版式：靛蓝色标题页、节标题页、页脚课程名和页码）。

## 工作流程

1. `python tools/make_slides.py draft NN`：从正文机械摘出底稿（每个小节一页，取每段第一句）。**底稿不能直接用**，正文摘句太长、太多。
2. 把底稿精简成“一页一个要点”：每章 15–30 页，每页 3–6 条，每条不超过 30 字；讲解的话放进 `::: notes`（PowerPoint 的演讲者备注），不放在页面上。
3. `npm run figures`：渲染 Mermaid 图和交互动画截图（没渲染时课件里显示灰色提示框）。
4. `python tools/make_slides.py build NN`，用 PowerPoint 或 WPS 打开检查。

## 写法

````markdown
---
chapter: 6
---

## 学习目标                     ← 二级标题：一页内容页，标题就是页标题
- **说出**文本分类的定义         ← 列表：要点；**加粗**显示为强调色，`代码` 用等宽字体
  - 二级要点                     ← 缩进两个空格是下一级

# 6.4 分类效果的评价             ← 一级标题：节标题页（过渡页）

## 混淆矩阵
| | 预测为差评 | 预测为好评 |      ← 表格：表头自动着色
|---|---|---|
| 实际是差评 | TP | FN |

## 拖一拖阈值
!sim threshold-confusion         ← 交互动画：截图 + 二维码 + 网址，扫码就能在手机上操作
- 阈值升高，召回率升高            ← 有图又有要点时，图在左、要点在右

## 机器学习流程
!mermaid 2                       ← 本章正文中第 2 个 Mermaid 图（按出现顺序数）
![混淆矩阵](images/cm.png)       ← 图片，路径相对于本章目录 docs/chapters/NN-xxx/

## 课堂练习
!quiz 3                          ← 本章课后练习里第 3 道可在线作答的题，答案和解析自动放进备注

## 代码示例
```python
model.fit(X_train, y_train)      ← 代码块：等宽字体、灰底
```
::: notes
这一页讲……（演讲者备注，只有讲课的人看得到）
:::
````

标题页（章号、章名、课程名、学时）自动生成，不用写。

一页里的元素按这个优先级排版：课堂练习 → 图（动画、Mermaid、图片，可配要点） → 表格或代码（上面可配一两句话） → 纯要点。一页只放一张表或一段代码，放不下就拆成两页。
