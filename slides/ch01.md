# 1.1 什么是计算机网络

## 一条微信消息的旅程
!mermaid 1
- 手机 → 无线路由器或基站
- → 运营商网络，一站一站转发
- → 微信服务器 → 朋友的手机

::: notes
不到一秒，数据经过了手机、路由器、光纤、基站、服务器，跨越几十到上千公里。像快递一站一站转，是分组交换的直观印象，1.4 节展开。
:::

## 计算机网络的定义
| 关键词 | 意思 | 例子 |
|---|---|---|
| 功能独立 | 自己就能工作 | 断网照样能打字 |
| 线路和设备 | “路”和“路口” | 网线、光纤；交换机、路由器 |
| 共同的规则 | 说同一种“语言” | 协议，如 TCP/IP |
| 交换数据、共享资源 | 联网的目的 | 发消息、共用打印机 |

::: notes
这里的“计算机”是广义的：手机、智能电视、摄像头、打印机，只要能联网收发数据都算。网络的三大作用：通信、资源共享、提高可靠性和效率。
:::

## 互联网与互连网
- **互连网**（internet，小写）：多个网络连起来
- **互联网**（Internet，大写）：全球最大的那一个
  - 采用 **TCP/IP** 协议族
- 判断题常考：大小写别弄反

# 1.2 网络由什么组成

## 三类组成部分
| 组成部分 | 例子 | 比喻 |
|---|---|---|
| 端系统（主机） | 电脑、手机、服务器 | 寄件人、收件人 |
| 通信链路 | 网线、光纤、无线电波 | 公路 |
| 网络设备 | 交换机、路由器、光猫 | 路口、分拣站 |

::: notes
从另一个角度分：边缘部分（用户直接使用的端系统）和核心部分（大量网络和路由器，负责把数据送到）。
:::

## 小办公室的网络长什么样
!mermaid 2
- **光猫**：光信号 ↔ 电信号
- **无线路由器**：交换 + 路由 + WiFi + 分配地址
- 台式机、打印机用网线，手机用 WiFi

::: notes
无线路由器一个盒子里有好几样功能，第 8 章会拆开看。提示学生：排查问题前先画网络草图，实验 1-1 就要画。
:::

# 1.3 网络的分类

## 按覆盖范围分
| 类型 | 范围 | 例子 |
|---|---|---|
| 个人区域网 PAN | 约 10 米 | 蓝牙耳机、手表 |
| 局域网 LAN | 一栋楼、一个校园 | 工作室办公网 |
| 城域网 MAN | 一座城市 | 城市宽带骨干网 |
| 广域网 WAN | 跨城市、跨国家 | 运营商骨干网、互联网 |

## 按拓扑结构分
!mermaid 3
- **星形**：局域网最常用，中心坏了全瘫
- 总线形、环形：早期和工业网络
- 树形：核心 → 楼层 → 电脑
- **网状**：可靠，互联网核心

::: notes
星形和网状是重点：星形好管理，一根线坏只影响一台；网状有多条路径，一条断了走另一条。按使用者还可以分公用网和专用网。
:::

# 1.4 数据是怎样“交换”的

## 电路交换：打电话
- 先**建立连接**，独占一条通路
- 优点：稳定，延迟固定
- 缺点：计算机数据是**突发**的
  - 占着线却大部分时间空着
- 报文交换：整份报文存储转发（早期电报）

## 分组交换：寄快递
!mermaid 4
- 数据切成**分组**，每个带首部
- 路由器**存储转发**
- 不用先建连接，线路共享，利用率高
- 代价：首部开销、排队、可能丢包

## 三种方式比一比
!sim circuit-vs-packet
- 电路交换：独占、要建连接
- 报文、分组交换：共享、存储转发
- 互联网核心用**分组交换**（考点）

::: notes
动画里同一段时间内几对用户收发数据：电路交换每对独占一条，空闲时浪费；分组交换大家的分组交错传输。让学生说出线路利用率的差别。
:::

# 1.5 怎样说网络“好不好”

## 速率与带宽
- 单位：bit/s，常写 Mbps、Gbps
- 1 Mbps = 10⁶ bit/s（网络用 1000 进制）
- **1 字节 = 8 比特**
- 100 Mbps 宽带 ÷ 8 ≈ **12.5 MB/s**
- 吞吐量受**瓶颈链路**限制

::: notes
“100 兆宽带下载只有 11 MB/s”是最常见的疑问，答案就是单位不同。吞吐量是实际传输的速率，一条路径上速率最低的那段决定整体。
:::

## 时延的四个组成部分
| 时延 | 由什么决定 | 比喻 |
|---|---|---|
| 发送时延 | 数据长度 ÷ 发送速率 | 装车 |
| 传播时延 | 链路长度 ÷ 传播速度 | 路上开车 |
| 处理时延 | 设备性能，很短 | 看快递单 |
| 排队时延 | 拥挤程度，**变化最大** | 门口排队 |

## 算一算：两种时延
- 10 MB 文件，10 Mbps，距离 1000 km
- 发送时延 = 10×10⁶×8 ÷ 10×10⁶ = **8 s**
- 传播时延 = 10⁶ m ÷ 2×10⁸ m/s = **5 ms**
- 速率提到 100 Mbps：发送 0.8 s，传播**仍是 5 ms**

::: notes
关键结论：提高带宽只缩短发送时延，不改变传播时延。“高速链路”是比特推得快，不是信号跑得快，判断题常考。
:::

## 拖一拖：时延计算器
!sim delay-calculator
- 改数据量、速率、距离
- 看哪一项时延占大头

## 往返时间与丢包率
| 往返时间 | 感受 |
|---|---|
| < 5 ms | 同一局域网，极快 |
| 10～50 ms | 国内主流网站，很好 |
| 50～100 ms | 跨省、跨运营商，尚可 |
| > 150 ms | 视频会议、游戏明显卡 |

::: notes
用 ping 测往返时间（RTT）和丢包率，实验 1-2 做。回到情景：视频会议卡，可能是有人下载大文件把链路占满，排队时延和丢包增加。
:::

# 1.6 互联网的发展

## 几个关键年份
- 1969 ARPANET：第一个分组交换网
- 1983 全面改用 TCP/IP：互联网诞生
- 1989—1991 万维网出现
- **1994 年 4 月 20 日** 中国全功能接入互联网
- 2022 年起“东数西算”

## 标准由谁来定
| 组织 | 负责 | 例子 |
|---|---|---|
| IETF | 互联网协议，发布 **RFC** | IP、TCP、HTTP |
| IEEE | 局域网、无线局域网 | 802.3、802.11 |
| ITU | 电信、移动通信 | 5G |
| ISO | 国际标准 | OSI 模型 |

# 1.7 常见问题与 AI 与网络

|---|---|
